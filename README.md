# Strata Music Generation Test

2-minute ambient music generated by the local Strata environment with
**Qwen3.8-Flash-Next Coder IQ1_M** on an RTX 3060 12 GB.

The model is text/code-only, so it wrote a Python synthesizer; the synthesizer
produced the WAV and ffmpeg converted it to MP3.

## Files

- [music_2min.mp3](music_2min.mp3) - 2:00, 192 kbps, 44.1 kHz mono
- [music_2min.wav](music_2min.wav) - 2:00, 22,050 Hz, 16-bit mono
- [music_code.py](music_code.py) - model-generated synthesizer
- [Music-Test-Report.md](Music-Test-Report.md) - full test report
- [Installation-Report.txt](Installation-Report.txt) - Strata installation report

## Result

PASS. The 600-token completion cap truncated the final `wave.writeframes` line;
that one line was completed manually. All other synthesizer code is the model's
output. See the full report for timings and environment details.

All Strata files are kept under `G:\Strata`; no Strata files were written to C:
or D:.

11. UNRESOLVED ISSUES / LIMITATIONS
-----------------------------------
1. Speed is very low: about 0.2-0.5 tokens/s, because the model's 23.4 GB expert
   pack does not fit in the ~0.8-4 GB of free RAM and is read from the USB HDD.
   Short answers take 1-5 minutes. Long agentic coding sessions are impractical.
2. Free RAM is very low (about 0.8 GB observed at steady state) because many
   desktop applications are running. Closing memory-heavy applications would
   let the expert cache grow in RAM and improve speed.
3. Folding@home is intentionally paused while Strata runs so the engine can use
   the full VRAM (about 11.7-11.9 GB). Folding resumes when Stop-Strata.bat is
   used. If FAH must run concurrently, start Strata without the Start script;
   expect less VRAM for experts and slower answers.
4. The USB HDD reads at about 17-27 MB/s. A faster SSD/USB 3.2 connection would
   improve model loading and expert-cache misses substantially.
5. Long-context stress testing was not practical (32K is configured and
   accepted; prefill would take hours for very long prompts).
6. Thinking is off by default for client compatibility; enabling it is much
   slower on this machine.
7. `strata runtime status --profile launch-iq1_m-32k` can occasionally report
   "starting" while the API is already loaded; Check-Strata.bat therefore also
   checks GET /v1/models and the process list. The API itself is healthy (it
   showed "ready" in the final check).

These are performance limitations, not build failures. The model, GPU offload,
API, streaming and coding behavior were verified.
